Enterprise Gaming Platform Upgrade Program
Seminole Hard Rock Support Services
Problem
Upgrading gaming applications across 13 casino properties simultaneously carried significant risk — adverse effects to the gaming floor or system outages translated directly to revenue loss. A failed upgrade with no recovery path was not an acceptable outcome in a 24/7 regulated environment.
Action
Designed a phased rollout program using the 6 Florida properties as a controlled pilot group — geographically concentrated for rapid on-site support if needed. After all 6 properties signed off, the enterprise rollout was scheduled across all remaining properties in coordination with their Gaming Systems teams. Built rigorous rollback procedures into every upgrade, including both database and binary folder backups for each affected application prior to any production deployment. All changes were vigorously validated in QA before promotion to production.
Result
Delivered enterprise-wide gaming platform upgrades across all 13 properties with zero unplanned outages. The phased pilot model became the standard upgrade methodology, giving stakeholders confidence in the process and providing a proven rollback path that protected revenue and regulatory continuity at every property.
Player Database Pre-Migration Validation Tool
Light & Wonder
Problem
Legacy casino player management systems accumulated years of unvalidated "dirty data" — free-text fields where users had entered values like invalid state names, malformed phone numbers, and non-standard addresses. These failures were not discovered until migration was underway, causing go-live delays, failed records, and costly rework across every customer onboarding.
Action
Led the design and development of a pre-migration data comparison tool that analyzed all distinct field values in the source database against valid mapped values in the target system. The tool generated an Excel output flagging every unique value with no valid mapping — giving the team and the customer a complete data quality picture before a single record was touched. Customers were presented three options: remediate the data themselves, have the team remediate it, or accept failures for records deemed non-critical.
Result
Transformed data migration from a reactive, failure-driven process into a structured, customer-facing data quality program. Go-live risk dropped significantly, customer expectations were properly set before migration began, and the tool became standard pre-migration practice across all subsequent platform deployments in the customer portfolio.
IPTV Platform Migration and OpEx Reduction
Hard Rock Sacramento
Problem
The property launched with a commercial IPTV and video matrix solution requiring a dedicated set-top box on every screen. With hundreds of screens across the property, hardware replacement costs of approximately $600 per unit combined with expensive per-unit annual licensing made the solution financially unsustainable as an ongoing operational expense.
Action
Evaluated the existing solution against alternatives and proposed migrating to TriplePlay TV — a software-based IPTV platform that eliminated the set-top box requirement entirely by leveraging the onboard chipset built into the property's existing Samsung commercial displays. Managed the full vendor transition, negotiated a new MSA with significantly reduced per-unit licensing terms, and oversaw deployment across all screens property-wide.
Result
Eliminated ongoing hardware replacement costs and reduced per-unit licensing spend across hundreds of screens, contributing directly to reducing property OpEx from $2.5M to $1.8M. The property gained expanded marketing content customization capabilities and removed the hardware dependency that had constrained the original solution.
